# Unified OD&D launch patch (21 October 2026 source)

- Both first-join and returning-member launch links use `combat-grid.html?c=…`, with `welcome=1` for new players.
- `combat-grid.html` derives table PLAYER mode from the authenticated campaign membership after `game('open')` succeeds, before installing any watchers.
- Role changes restart subscriptions in-place instead of bouncing users between URLs. Signing out cleans up subscriptions and presence heartbeat timers.
- The same campaign overview appears for referee and player; players retain character creation/onboarding below it. The referee alone sees Open a fight.
- Player character watch remains filtered (`all: false`) and fight viewer remains uid-scoped. Authorization must additionally be enforced by Firebase rules/functions.
- Legacy `?player` standalone fight links continue to be supported; they are no longer generated by the canonical campaign launch flow.

## Verification

Run `node --test odd/test/unified-launch.test.mjs` from the repository root. Syntax checked with `node --check` on the extracted inline module script.

The functions test suite cannot run from the supplied ZIP by itself: it requires the sibling `packages/odd-chainmail-rules` package (not present in the uploaded odd directory). Full two-account Firebase emulator regression testing remains necessary before deployment, including first join, returning player, GM, promotion/demotion, live encounter, and sign-out.

## Installation

Replace the repository `odd/index.html` and `odd/combat-grid.html` with the files in this ZIP, and optionally add `odd/test/unified-launch.test.mjs`. Review/commit changes before deployment. No server files were changed.
